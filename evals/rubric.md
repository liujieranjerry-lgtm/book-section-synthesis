# 评分表

每个维度按 0–2 分评分：

- **2**：稳定、完整、无需人工修正。
- **1**：基本正确，但有遗漏、含糊或需要用户追问才能确认。
- **0**：失败，或出现了 skill 明确禁止的行为。

| 维度 | 2 分 | 1 分 | 0 分 |
|---|---|---|---|
| Source gate | 无原文时先要求原文，不输出梳理正文；有原文时确认版本与边界 | 要求了原文，但先写了推测性内容，或版本/边界确认不完整 | 凭书名、记忆或二手介绍代写 |
| 边界 | 边界明确，无下一小节内容；歧义处理正确 | 边界说明含糊，或需要用户再次确认 | 边界错误，或混入下一小节 |
| 覆盖 | 原文主要结构推进全部进入梳理；承担论证的图表/公式/注释未遗漏 | 漏掉次要环节或部分注释 | 漏掉主要环节，或只做摘要 |
| 保真 | 无无来源主张；外部补充已标注；推断与原文主张分开 | 有一两处标记不清，但没有实质曲解 | 虚构作者立场、引文或理论关联 |
| 类型/结构 | 正确识别主导类型并选对骨架；混合类型处理合理 | 主导类型基本正确，但有轻微硬套 | 把非论证型强行写成论证文，或结构误导 |
| 术语/读者 | 按用户知识基础解释；无过度解释，无关键遗漏 | 解释密度略偏，但基本可读 | 大量解释常识，或完全不解释关键术语 |
| 篇幅/输出 | 标准模式 4–8 段，紧凑 2–4 段；格式符合请求 | 段落数略超出，或格式有小问题 | 严重注水、严重超长，或完全不符合请求 |
| 交互/澄清 | 缺少原文或知识基础时，用最少的问题问清；不重复追问 | 问了但不够聚焦，或多轮往返 | 该问不问，或反复追问已确认的信息 |
| 错误处理 | 正确区分内部矛盾、翻译问题和事实争议；事实争议要求外部证据 | 分类基本正确，但证据标准含糊 | 凭记忆判定事实错误，或把推断当事实 |
| 版权/隐私 | 无长段逐字复制；引文简短并标注；输出不替代原文 | 引文略多，但没有实质复制 | 大段复制原文，或复现整节内容 |

总分 18。建议通过线：14 分及以上，且 `Source gate`、`保真`、`边界` 均不低于 1。
