# 评分表（v3：整章梳理）

对 skill 3.0.0。12 个维度，每维 0–2 分，满分 24 分。

## 刻度

- **2**：稳定、完整、无需人工修正。
- **1**：基本正确，但有遗漏、含糊，或需要用户追问才能确认。
- **0**：失败，或出现了 skill 明确禁止的行为。

维度名与 [fixtures/cases.md](fixtures/cases.md) 的「评分重点」一致。

## 维度与交付门的对应

| 维度 | 对应规则 |
|---|---|
| Source gate | 第 0 步：原文可得、版本可定、边界可定、文字层门槛 |
| 边界 | 交付门 1；章末附属部分的默认值 |
| 覆盖 | 交付门 2；第 3 步逐节梳理 |
| 主线 | 交付门 4；第 1–2 步；[text-types.md](../skill/book-section-synthesis/references/text-types.md)（章层类型只影响主线写法与分组） |
| 收束 | 交付门 5；第 4 步 |
| 顺序 | 交付门 3；第 3 步 |
| 篇幅 | 交付门 6；「字数与篇幅」 |
| 标注与保真 | 交付门 7、10；[fidelity.md](../skill/book-section-synthesis/references/fidelity.md) |
| 术语与读者档位 | 交付门 8；第 5 步；五问第 1、2 题 |
| 交互 | 「开始前的五个问题」 |
| 错误处理 | 交付门 9；第 6 步；fidelity.md 错误三分类 |
| 版权 | 交付门 10；fidelity.md 引用规则 |

为什么是 12 个而不是 10 个：交付门 3（顺序）与 4（主线）的失败方式不同——调换节序与目录复述是两类错误，分开记才能定位；交付门 10 的「把推断写成作者原话」与「逐字复制」也是两类失败，分入「标注与保真」「版权」。章层类型不单列，因为它只影响主线写法与逐节分组，合并进「主线」。

## 评分表

| 维度 | 2 分 | 1 分 | 0 分 |
|---|---|---|---|
| Source gate | 无原文时先拒答并索要（粘贴／文件／路径／图片），不写正文；有原文时确认版次、章号章名与起止；文字层不足时报字符数并要 OCR 或图片 | 要了原文但同时写了推测内容；或版本／边界只确认一半；或文字层偏低仍照写 | 凭书名、目录、记忆或二手介绍代写；或拿 1,860 字硬梳 8 节章 |
| 边界 | 起止正确；Notes／Further Reading／节末练习按名称识别并各归其位（论证性 Notes 随文并注「Notes k」；Further Reading 忽略或末节一句括注；练习放该节末尾、题号＋要点、不逐字抄、不计字数）；节数报对 | 起止对，但附属部分有一处处理不当：练习计入字数、Further Reading 写了不止一句括注、Notes 全删或全收 | 混入下一章；把 Further Reading 或 Notes 当节写进正文；漏掉承担论证功能的 Notes 或整节练习 |
| 覆盖 | 每节都有对应标题与内容；承担论证功能的图、注释、边栏都已纳入；练习按题号＋要点保留 | 漏一处边栏或一条论证性注释，或某节只剩一句 | 漏整节；把章写成摘要；图表只描述外观、不写论证作用 |
| 主线 | 先判章层类型（论证／综述／史论／导论），再按其写法给主线（论证型强制链、综述型排列依据与争点、史论型分期依据、导论型版图分区）；判不出则按原文标题结构并记「未归入某一章层类型」；删掉全部节号仍读得通；每句为强制关系（导论型允许只写位置关系）；章首栏目与导言并入 | 类型判对但主线有 1–2 句「先…然后」的目录句；或类型判错但主线仍是逻辑推进 | 目录复述或串讲；硬套类型压过原文；为套类型改动节序 |
| 收束 | 标准／详细：末节后、术语注前，立场地图、代价对称性、未解决问题三件齐全，未重列各节结论，未引入章外内容（需要时只走已开启的补充背景）。简略：三件并入末段收口，不另开节、不再完整展开。模式③ 不写，写了即 0 | 三件缺一，或有一处轻微重列 | 写成逐节结论的压缩版；引入章外材料；把末节结论原样搬来当收束 |
| 顺序 | 逐节严格原文顺序；标题用原文措辞；分组只写在主线，不新增小标题层级 | 顺序对，但合并了两节或改了标题措辞 | 为「讲起来更顺」调换或合并节；把主线重组扩到逐节 |
| 篇幅 | 字数一律按**去标点**计（中文字符、数字、外文各计 1）；正文落在档位区间（简略 40–80／节、标准 250–350／节、详细 400–700／节；主线与收束按表），或已记偏差；最长／最短 > 1.75 时按占比分配，各节在份额 0.6–1.4 倍（纯列举 0.5），地板（40／100／250）已生效；术语注、练习、审校、存疑项不计入；超 12,000 按序降级并记录。模式③ 锁简略 | 区间边缘；一处份额越界未记录；或占比分配大体对但一节明显失衡 | 严重超长或过短；把术语注计入正文；长短悬殊仍等长平摊；超限不降级也不记录 |
| 标注与保真 | 四类来源分开：作者主张用陈述句；转述他人用「（引 X）」；`*诠释*：` 斜体只包两字、冒号在外，每节 ≤4 处，只用于蕴含推理与立场代价；补充背景仅在开关开启时 ≤5 处且已标记；作者对引用的批判另起一句 | 一两处标记不清（诠释多一处、背景标记不全），无实质曲解 | `*诠释：` 吞段；把推断写成作者原话；把转述当作者主张或与之合并；虚构引文或立场 |
| 术语与读者档位 | 条数合模式（①15–30、②15–40、③不设）且简略档 ≤10；每条带节号（图／边栏／注写「8.4 图 8.1」式）；② 附原文词形；密度按读者档（①展开核心与背景、②只释本书特有、③只释自创改用、④只记特殊用法与偏差）；文中零行内注释 | 条数差 1–3 条，或少量缺节号；密度略偏 | 模式③ 设注；条数越界（如② 收 55 条）；通篇解释学科常识；正文出现行内注释 |
| 交互 | 五问一条消息编号列全（用户已说明的项跳过，其余一次列全，说明跳过依据）；问档位前报「本章共 N 节」，档位选项给每节与全章字数；模式③ 跳过档位；用户说「都用默认」即取 ②／①／标准／不加／不做，不重复追问，文件头记假设 | 分两轮问；漏报节数；档位只给全章一个数；默认值取了但文件头未记 | 边写边问；不问就写；对已答信息反复追问；模式③ 仍问档位 |
| 错误处理 | 审校单开一节、在存疑项之前，三分类正确（内部矛盾／翻译编辑／事实争议），证据标准对（内部凭本章；翻译无原文不断言；事实要外部来源）；存疑项 ≤3 行，只留三类，缺类省略、不写「无」；选了审校则只留未能核实 | 分类基本对但证据标准含糊；存疑项多一行「无」或略超三行 | 凭记忆判定事实错误；把翻译问题断为原文错误；存疑项三行全「无」；审校条目在存疑项重复 |
| 版权 | 无长段逐字复制；只在精确措辞影响理解处短引（单次一两句），引后说明作用；转述优先；输出不替代原文 | 引文偏多（3–5 处或个别超过两句），但未成段复制 | 整段搬原文；用同义词替换保留原文骨架；输出可直接替代原文 |

## 通过线与硬线

- 通过线：**总分 ≥ 18 / 24**。
- 硬线：**Source gate、边界、标注与保真** 三个维度均须 ≥ 1；任一为 0，整体不通过，即使总分 ≥ 18。
- 无原文用例（case 03）的 Source gate 必须为 **2**；给 1 也不通过——「先写一段再要原文」正是该用例要抓的行为。
- 多轮用例每轮分别记分；任一轮硬线为 0，该用例不通过。
- 模式③ 口径：「术语与读者档位」不设术语注得 2，设了得 0；「收束」不写三件事得 2，写了得 0；「主线」按后部关系段评，不要求「全章主线」标题。
- 评分顺序：先过硬线，再看总分。不要用高分掩盖硬线失败，也不要因为总分达标就放过 0 分项。
